# Glacier calving 
This project presents a spatiotemporal deep learning framework for glacier calving risk prediction using satellite-derived glacier velocity observations. Glacier calving, which refers to the detachment of large ice masses from glacier termini, is a major contributor to glacier retreat and global sea-level rise. Existing glacier monitoring approaches primarily focus on calving-front detection and post-event analysis, with limited emphasis on predictive forecasting of glacier instability.  The proposed framework, termed Spatiotemporal Graph Attention Network (ST-GATT), integrates remote sensing, anomaly detection, graph neural networks, and temporal forecasting into a unified glacier early-warning system. Temporal glacier velocity maps obtained from satellite observations are analyzed using Seasonal-Trend decomposition using Loess (STL) and Z-score-based anomaly detection to identify abnormal glacier acceleration patterns associated with potential calving events. Glacier regions are represented as interconnected graph nodes to model spatial interactions and stress propagation within the glacier system.  The framework combines Graph Attention Networks (GAT) for spatial dependency modeling with Transformer-based temporal learning to capture evolving glacier dynamics across time. By jointly learning spatial and temporal glacier behavior, the framework predicts calving risk within a 2–4 week forecasting horizon and generates spatial risk heatmaps highlighting unstable glacier regions.  Experimental evaluation using satellite-derived glacier velocity data demonstrated strong predictive performance, achieving an AUROC of 0.9444 and an AUPRC of 0.8333. The proposed framework demonstrates the potential of combining remote sensing, anomaly-aware forecasting, and spatiotemporal graph learning for glacier instability prediction and climate-risk monitoring.
